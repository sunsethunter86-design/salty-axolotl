VOICE SOURCE AND POCKET TTS (CC BY 4.0)
----------------------------------------

The current owner-promoted Veridity voice state is conditioned from two original
VCTK p303 recordings: `p303_146_mic1.flac` and `p303_023_mic1.flac`. Both audio
references were scaled by +2 dB before Pocket TTS encoding; selected encoded
donor/anchor spans were combined into the 162-step conditioning state and then
flattened for the local ONNX runtime.

The pure-p303 rollback state instead uses Kyutai's enhanced VCTK source clip
`vctk/p303_023_enhanced.wav`, distributed in its TTS voice collection:
https://huggingface.co/kyutai/tts-voices

Corpus credit:
Yamagishi, Junichi; Veaux, Christophe; MacDonald, Kirsten. (2019).
CSTR VCTK Corpus: English Multi-speaker Corpus for CSTR Voice Cloning Toolkit
(version 0.92), [sound]. University of Edinburgh, The Centre for Speech
Technology Research (CSTR). https://doi.org/10.7488/ds/2645

Changes were made. Kyutai describes the enhanced rollback source as cleaned
with ai-coustics to reduce noise and reverberation. For Veridity Flow, both the
current composite and rollback were converted into Pocket TTS conditioning
states, adapted to the exported ONNX input manifest, and flattened for the
local mobile runtime. These changes and this app are not endorsed by the
original creators.
The released/approved voice states contain p303 material only; no Expresso or
Cosette material is included. The historical device basename contains
`mesh20`, but the basename is not provenance and is accepted only when its full
SHA-256 is one of these pure-p303 states:

- owner-promoted state:
  860A94A55A84028A045038EA78449064BFC7B794FD23F3408F8E68E0F8DB4236
- pure-p303 rollback state:
  51BCA0C2C866B0A10CD0567EF0D71D39A329AA7AEBD33A0A919C697B98AFDCC8

The VCTK voice material in Kyutai's collection is licensed under Creative
Commons Attribution 4.0 International (CC BY 4.0):
https://creativecommons.org/licenses/by/4.0/

Pocket TTS model by Kyutai:
https://huggingface.co/kyutai/pocket-tts
License: CC BY 4.0

The Pocket TTS ONNX export used for the mobile runtime is derived from Pocket
TTS. Exact export/model source and commit:
https://huggingface.co/KevinAHM/pocket-tts-onnx
58a6d00cf13d239b6748cb0769f35c580a8f606c
The exact-commit model card declares its exporter code under Apache License 2.0
and its converted model assets under CC BY 4.0, inherited from Pocket TTS.

The delivery pack uses the exact `english_2026-04` bundle metadata and fp32
`flow_lm_main`, `flow_lm_flow`, `mimi_decoder`, and `text_conditioner` graph
bytes from that commit. Veridity repacks those files with its precision marker,
locally pinned SentencePiece tokenizer graph, approved p303 state, and tuning
sidecars. ZIP entry timestamps are normalized; the pinned upstream graph bytes
are not modified. The local tokenizer graph is pinned by size and SHA-256, but
no conversion-recipe receipt for it was present in the audited source tree, so
no stronger upstream-origin claim is made here.

TERMS REVIEW REQUIRED BEFORE PUBLIC VOICE HOSTING
The Kyutai Pocket TTS model card currently uses gated access and carries a
prohibited-use attestation. The exact ONNX-export commit also states prohibited
uses, including unauthorized voice impersonation and deceptive uses. CC BY 4.0
identifies the model licence, but the source tree does not prove which gated
terms the downloader accepted or whether the intended public hosting satisfies
them. Public release remains blocked on an owner/legal review of those accepted
terms and the authority to redistribute this derived delivery pack. Code and
attribution work cannot decide that question.
